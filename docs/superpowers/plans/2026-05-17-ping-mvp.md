# Ping MVP Implementation Plan

> 2026-05-17 현 구현은 Spark 요금제 제약 때문에 이 초기 계획의 Firebase Storage/Firestore TTL 항목을 대체한다. Firebase Storage는 Blaze가 필요하므로 사용하지 않고, 영상은 Firestore `videoChunks` 청크로 저장한다. Firestore TTL deletes도 Spark 무료 한도에 포함되지 않아 앱 실행 시 클라이언트 best-effort cleanup으로 만료 데이터를 정리한다. 이 파일의 Storage/TTL 관련 단계는 historical plan으로만 취급한다.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** macOS 26 전용, 메뉴바 상주, Option+P로 2초 영상 메시지를 1:1 다중 파트너에게 즉시 전송하는 SwiftUI 앱 MVP를 1주일 내 완성하여 ad-hoc 서명된 DMG로 배포한다.

**Architecture:** SwiftUI + AppKit (NSWindow 직접 제어), MVVM with `AppState` ObservableObject. Backend는 Firebase Anonymous Auth + Firestore (실시간 listener) + Storage. 푸시 인프라 없이 메뉴바 상주 + Firestore listener + `UNUserNotificationCenter` 로컬 알림으로 우측 상단 배너 발생. 글래스모피즘 UI는 macOS 26 네이티브 `.glassEffect()` API 사용. XcodeGen으로 `.xcodeproj` 재현 생성, SPM으로 의존성 관리, `create-dmg`로 배포 패키징. Xcode IDE 불필요 (CLI-only workflow).

**Tech Stack:** Swift 6.0+, SwiftUI, AppKit, AVFoundation, UserNotifications, ServiceManagement, Firebase iOS SDK 11.x, KeyboardShortcuts 2.x, XcodeGen, create-dmg.

**Reference Spec:** `PING_PROJECT_SPECIFICATION.md` (v2.0)

**Agent Onboarding:** Read `AGENTS.md` (project root) BEFORE starting any task. It captures critical "do not downgrade" rules for macOS 26 / Swift 6 / `.glassEffect()` API, Single Source of Truth values (Bundle ID, Firebase Project ID), and known pitfalls.

import Foundation

enum ScreenCoordinates {

    static func normalize(point: CGPoint, in screen: CGRect) -> MirrorPosition {
        MirrorPosition(
            xRatio: (point.x - screen.minX) / screen.width,
            yRatio: (point.y - screen.minY) / screen.height
        )
    }

    static func denormalize(position: MirrorPosition, in screen: CGRect) -> CGPoint {
        CGPoint(
            x: screen.minX + screen.width * position.xRatio,
            y: screen.minY + screen.height * position.yRatio
        )
    }

    static func clamp(point: CGPoint, windowSize: CGSize, inSafeArea safe: CGRect) -> CGPoint {
        CGPoint(
            x: min(max(point.x, safe.minX), safe.maxX - windowSize.width),
            y: min(max(point.y, safe.minY), safe.maxY - windowSize.height)
        )
    }
}

import Foundation

enum SearchableText {
    static func normalize(_ s: String) -> String {
        s.lowercased().filter { !$0.isWhitespace }

    static func matchesPrefix(target: String, query: String) -> Bool {

import AVFoundation
import AppKit

@MainActor
final class VideoRecorder: NSObject, AVCaptureFileOutputRecordingDelegate {
    private let movieOutput: AVCaptureMovieFileOutput
    private var continuation: CheckedContinuation<URL, Error>?

    init(output: AVCaptureMovieFileOutput) {
        self.movieOutput = output
    }

    /// 정확히 2초간 녹화하고 파일 URL 반환.
    func recordTwoSeconds() async throws -> URL {
        let tempURL = FileManager.default.temporaryDirectory
            .appendingPathComponent("ping-\(UUID().uuidString).mp4")

        movieOutput.maxRecordedDuration = CMTime(seconds: 2.0, preferredTimescale: 600)
        movieOutput.startRecording(to: tempURL, recordingDelegate: self)

        return try await withCheckedThrowingContinuation { cont in
            self.continuation = cont
        }
    }

    nonisolated func fileOutput(_ output: AVCaptureFileOutput,
                                didFinishRecordingTo outputFileURL: URL,
                                from connections: [AVCaptureConnection],
                                error: Error?) {
        Task { @MainActor in
            if let error {
                let nsErr = error as NSError
                // maxRecordedDuration 도달도 error로 들어오지만 정상 케이스.
                let isReachedMax = nsErr.userInfo[AVErrorRecordingSuccessfullyFinishedKey] as? Bool == true
                if isReachedMax || error == nil {
                    continuation?.resume(returning: outputFileURL)
                } else {
                    continuation?.resume(throwing: error)
                }
            } else {
                continuation?.resume(returning: outputFileURL)
            }
            continuation = nil
        }
    }
}

@MainActor
final class MirrorWindow: NSWindow {

    static let size = NSSize(width: 200, height: 200)
    private static let positionKey = "ping.mirror.lastPosition"

    init<Content: View>(rootView: Content) {
        let initialRect = NSRect(origin: Self.loadLastPosition(), size: Self.size)
        super.init(
            contentRect: initialRect,
            styleMask: [.borderless, .resizable],
            backing: .buffered,
            defer: false
        )
        isOpaque = false
        backgroundColor = .clear
        level = .floating
        hasShadow = false
        isMovableByWindowBackground = true
        ignoresMouseEvents = false
        collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]

        let host = NSHostingView(rootView: AnyView(rootView))
        host.frame = NSRect(origin: .zero, size: Self.size)
        contentView = host
    }

    static func loadLastPosition() -> NSPoint {
        let defaults = UserDefaults.standard
        if let dict = defaults.dictionary(forKey: positionKey),
           let x = dict["x"] as? CGFloat,
           let y = dict["y"] as? CGFloat {
            return NSPoint(x: x, y: y)
        }
        guard let screen = NSScreen.main else { return .zero }
        let f = screen.visibleFrame
        return NSPoint(x: f.midX - size.width / 2, y: f.midY - size.height / 2)
    }

    func savePosition() {
        UserDefaults.standard.set(
            ["x": frame.origin.x, "y": frame.origin.y],
            forKey: Self.positionKey
        )
    }

    override func mouseUp(with event: NSEvent) {
        super.mouseUp(with: event)
        savePosition()
    }
}

enum LocalArchive {

    static func documentsRoot() -> URL {
        let fm = FileManager.default
        let docs = fm.urls(for: .documentDirectory, in: .userDomainMask).first!
        return docs.appendingPathComponent("Ping", isDirectory: true)

@MainActor
final class RoomService {
    let db = FirebaseClient.shared.db

    /// 룸 생성. 생성자는 자동으로 멤버에 포함된다.
    @discardableResult
    func createRoom(name: String, ownerUid: String, ownerNickname: String) async throws -> Room {
        let ref = db.collection("rooms").document()
        let room = Room(
            id: ref.documentID,
            name: name,
            searchableName: SearchableText.normalize(name),
            ownerUid: ownerUid,
            memberUids: [ownerUid],
            memberNicknames: [ownerUid: ownerNickname],
            status: .open,
            createdAt: nil
        )
        try ref.setData(from: room)
        try await db.collection("users").document(ownerUid).updateData([
            "rooms": FieldValue.arrayUnion([ref.documentID])
        ])
        return room
    }

    func observeMyRooms(uid: String) -> AsyncStream<[Room]> {
        AsyncStream { continuation in
            let l = db.collection("rooms")
                .whereField("memberUids", arrayContains: uid)
                .addSnapshotListener { snap, _ in
                    let rooms = snap?.documents.compactMap { try? $0.data(as: Room.self) } ?? []
                    continuation.yield(rooms)
                }
            continuation.onTermination = { _ in l.remove() }
        }
    }

    func searchOpenRooms(prefix: String) async throws -> [Room] {
        let normalized = SearchableText.normalize(prefix)
        guard !normalized.isEmpty else { return [] }
        let end = normalized + "\u{f8ff}"
        let snap = try await db.collection("rooms")
            .whereField("status", isEqualTo: "open")
            .whereField("searchableName", isGreaterThanOrEqualTo: normalized)
            .whereField("searchableName", isLessThan: end)
            .limit(to: 20)
            .getDocuments()
        return snap.documents.compactMap { try? $0.data(as: Room.self) }
    }

    /// 트랜잭션으로 자신을 멤버에 추가하고 full로 전환.
    func joinRoom(roomId: String, uid: String, nickname: String) async throws {
        _ = try await db.runTransaction { txn, errorPointer -> Any? in
            let ref = self.db.collection("rooms").document(roomId)
            let snap: DocumentSnapshot
            do { snap = try txn.getDocument(ref) }
            catch { errorPointer?.pointee = error as NSError; return nil }
            guard var data = snap.data() else { return nil }
            var members = data["memberUids"] as? [String] ?? []
            guard members.count < 2, !members.contains(uid) else { return nil }
            members.append(uid)
            var nicknames = data["memberNicknames"] as? [String: String] ?? [:]
            nicknames[uid] = nickname
            data["memberUids"] = members
            data["memberNicknames"] = nicknames
            data["status"] = "full"
            txn.setData(data, forDocument: ref)
            return nil
        }
        try await db.collection("users").document(uid).updateData([
            "rooms": FieldValue.arrayUnion([roomId])
        ])
    }

    func leaveRoom(roomId: String, uid: String) async throws {
        let ref = db.collection("rooms").document(roomId)
        _ = try await db.runTransaction { txn, errPointer -> Any? in
            let snap: DocumentSnapshot
            do { snap = try txn.getDocument(ref) } catch { errPointer?.pointee = error as NSError; return nil }
            guard var data = snap.data() else { return nil }
            var members = (data["memberUids"] as? [String] ?? []).filter { $0 != uid }
            var nicknames = data["memberNicknames"] as? [String: String] ?? [:]
            nicknames.removeValue(forKey: uid)
            data["memberUids"] = members
            data["memberNicknames"] = nicknames
            data["status"] = members.count < 2 ? "open" : "full"
            txn.setData(data, forDocument: ref)
            return nil
        }
        try await db.collection("users").document(uid).updateData([
            "rooms": FieldValue.arrayRemove([roomId])
        ])
    }

    func renameRoom(roomId: String, newName: String) async throws {
        try await db.collection("rooms").document(roomId).updateData([
            "name": newName,
            "searchableName": SearchableText.normalize(newName)
        ])
    }
}

@MainActor
final class MessageService {
    let db = FirebaseClient.shared.db
    let storage = StorageService()
    let userService = UserService()

    struct SendInput {
        let rooms: [Room]              // 1개 = 단일, 2+ = 전체 발송
        let localVideoURL: URL
        let mirrorPosition: MirrorPosition
        let senderUid: String
        let senderNickname: String

            localURL: input.localVideoURL,
            senderUid: input.senderUid,
            messageId: messageId
        )

        let expires = Date().addingTimeInterval(24 * 60 * 60)
        let batch = db.batch()

        for room in input.rooms {
            guard let roomId = room.id,
                  let receiverUid = room.memberUids.first(where: { $0 != input.senderUid })
            else { continue }

            let docRef = db.collection("messages").document()

                roomId: roomId,
                senderUid: input.senderUid,
                receiverUid: receiverUid,
                senderNickname: input.senderNickname,
                videoUrl: videoUrl,
                durationMs: 2000,
                mirrorPosition: input.mirrorPosition,
                status: .uploaded,
                createdAt: nil,
                expiresAt: expires
            )
            try batch.setData(from: msg, forDocument: docRef)
        }

        try await batch.commit()

        // 마지막 사용 룸 업데이트 (단일 발송일 때만)
        if input.rooms.count == 1, let roomId = input.rooms[0].id {
            try await userService.updateLastUsedRoom(uid: input.senderUid, roomId: roomId)
        }

            let l = db.collection("messages")
                .whereField("receiverUid", isEqualTo: uid)
                .whereField("status", isEqualTo: "uploaded")
                .addSnapshotListener { snap, _ in
                    guard let changes = snap?.documentChanges else { return }

                            continuation.yield(msg)
                        }
                    }
                }
            continuation.onTermination = { _ in l.remove() }
        }
    }

@MainActor
final class AppState: ObservableObject {
    static let shared = AppState()

    @Published var currentUser: PingUser?
    @Published var rooms: [Room] = []
    @Published var pendingInvitations: [Invitation] = []
    @Published var sendMode: SendMode = .singlePartner

        return rooms.first(where: { $0.id == lastId }) ?? rooms.first
    }

    /// Tab 키로 다음 파트너로 이동
    func cycleToNextPartner(currentRoomId: String?) -> Room? {
        guard !rooms.isEmpty else { return nil }
        if let current = currentRoomId,
           let idx = rooms.firstIndex(where: { $0.id == current }) {
            return rooms[(idx + 1) % rooms.count]
        }
        return rooms.first
    }

    /// N번째 파트너 직접 선택 (1-indexed)
    func selectPartner(at index: Int) -> Room? {
        guard index >= 1, index <= rooms.count else { return nil }
        return rooms[index - 1]
    }
}

import UserNotifications
import AppKit

@MainActor
final class LocalNotificationCenter: NSObject, UNUserNotificationCenterDelegate {
    static let shared = LocalNotificationCenter()
    private override init() {
        super.init()
        UNUserNotificationCenter.current().delegate = self
    }

    enum Category: String {
        case incomingMessage = "ping.message"
        case incomingInvitation = "ping.invitation"
    }

    enum Action: String {
        case viewMessage = "ping.view"
        case acceptInvite = "ping.accept"
        case rejectInvite = "ping.reject"
    }

    /// onView: (messageId) -> Void
    /// onAccept/onReject: (inviteId) -> Void
    var onViewMessage: ((String) -> Void)?
    var onAcceptInvitation: ((String) -> Void)?
    var onRejectInvitation: ((String) -> Void)?

    func requestAuthorization() async -> Bool {
        do {
            let granted = try await UNUserNotificationCenter.current()
                .requestAuthorization(options: [.alert, .sound, .badge])
            await registerCategories()
            return granted
        } catch {
            return false
        }
    }

    private func registerCategories() async {
        let viewAction = UNNotificationAction(
            identifier: Action.viewMessage.rawValue,
            title: "보기", options: [.foreground])
        let messageCat = UNNotificationCategory(
            identifier: Category.incomingMessage.rawValue,
            actions: [viewAction], intentIdentifiers: [], options: [])

        let accept = UNNotificationAction(
            identifier: Action.acceptInvite.rawValue,
            title: "수락", options: [.foreground])
        let reject = UNNotificationAction(
            identifier: Action.rejectInvite.rawValue,
            title: "거부", options: [.destructive])
        let inviteCat = UNNotificationCategory(
            identifier: Category.incomingInvitation.rawValue,
            actions: [accept, reject], intentIdentifiers: [], options: [])

        UNUserNotificationCenter.current().setNotificationCategories([messageCat, inviteCat])
    }

    func notifyIncomingMessage(senderNickname: String, messageId: String) {
        let content = UNMutableNotificationContent()
        content.title = "\(senderNickname)님이 영상을 보냈습니다"
        content.sound = .default
        content.categoryIdentifier = Category.incomingMessage.rawValue
        content.userInfo = ["messageId": messageId]

        let req = UNNotificationRequest(
            identifier: "ping.msg.\(messageId)",
            content: content, trigger: nil)
        UNUserNotificationCenter.current().add(req, withCompletionHandler: nil)
    }

    func notifyIncomingInvitation(_ inv: Invitation) {
        let content = UNMutableNotificationContent()
        content.title = "\(inv.fromNickname)님이 룸에 초대했습니다"
        content.body = inv.roomName
        content.sound = .default
        content.categoryIdentifier = Category.incomingInvitation.rawValue
        content.userInfo = ["inviteId": inv.id ?? ""]

        let req = UNNotificationRequest(
            identifier: "ping.inv.\(inv.id ?? UUID().uuidString)",
            content: content, trigger: nil)
        UNUserNotificationCenter.current().add(req, withCompletionHandler: nil)
    }

    nonisolated func userNotificationCenter(
        _ center: UNUserNotificationCenter,
        didReceive response: UNNotificationResponse,
        withCompletionHandler completionHandler: @escaping () -> Void
    ) {
        let info = response.notification.request.content.userInfo
        Task { @MainActor in
            switch response.actionIdentifier {
            case Action.viewMessage.rawValue, UNNotificationDefaultActionIdentifier:
                if let id = info["messageId"] as? String {
                    onViewMessage?(id)
                }
                if let id = info["inviteId"] as? String, !id.isEmpty {
                    onAcceptInvitation?(id)   // 기본 액션 = 수락 화면 열기
                }
            case Action.acceptInvite.rawValue:
                if let id = info["inviteId"] as? String { onAcceptInvitation?(id) }
            case Action.rejectInvite.rawValue:
                if let id = info["inviteId"] as? String { onRejectInvitation?(id) }
            default: break
            }
            completionHandler()
        }
    }

    nonisolated func userNotificationCenter(
        _ center: UNUserNotificationCenter,
        willPresent notification: UNNotification,
        withCompletionHandler completionHandler: @escaping (UNNotificationPresentationOptions) -> Void
    ) {
        completionHandler([.banner, .sound])
    }
}

> **⚠️ Entitlements 파일 경로 확인 필수**: 아래 스크립트는 `--entitlements Ping.entitlements` 가 프로젝트 루트에 있다고 가정합니다. XcodeGen 버전에 따라 `Ping/Ping.entitlements` 일 수도 있으므로 첫 실행 전 다음으로 확인하고 다르면 스크립트 수정:
> ```bash
> find . -name "Ping.entitlements" -not -path "./build/*" 2>/dev/null
> ```

- [ ] **Step 1: 빌드 스크립트**

Create `scripts/build-release.sh`:
```bash
#!/usr/bin/env bash
set -euo pipefail

cd "$(dirname "$0")/.."

xcodegen generate

xcodebuild \
  -project Ping.xcodeproj \
  -scheme Ping \
  -configuration Release \
  -derivedDataPath build \
  clean build

APP="build/Build/Products/Release/Ping.app"

# ad-hoc sign
codesign --force --deep --sign - \
         --options runtime \
         --entitlements Ping.entitlements \
         "$APP"

codesign --verify --deep --strict --verbose=2 "$APP"

VERSION=$(/usr/libexec/PlistBuddy -c "Print CFBundleShortVersionString" "$APP/Contents/Info.plist")

mkdir -p dist
rm -f "dist/Ping-v$VERSION.dmg"

create-dmg \
  --volname "Ping Installer" \
  --window-size 500 300 \
  --icon-size 100 \
  --icon "Ping.app" 125 150 \
  --app-drop-link 375 150 \
  "dist/Ping-v$VERSION.dmg" \
  "$APP"

echo "✅ Built dist/Ping-v$VERSION.dmg"
```

Make executable:
```bash
chmod +x scripts/build-release.sh
```

- [ ] **Step 2: README**

Create `README.md`:
```markdown
# Ping

2초 영상 메시지 macOS 전용 앱. Option+P 한 번으로 친구에게 보낸다.

## 설치 (수신자용)

1. `Ping-v0.1.0.dmg` 더블클릭 → 마운트.
2. Ping.app을 Applications 폴더로 드래그.
3. **첫 실행은 우클릭 → "열기"** → 경고 다이얼로그에서 "열기" 클릭. (ad-hoc 서명 앱이라 Gatekeeper 경고 우회 필요)
4. 카메라 / 마이크 / 알림 권한을 허용.
5. 닉네임 입력 후 룸을 만들거나 상대를 검색해서 초대를 보낸다.

## 사용

- **Option+P** — 어디서든 거울을 띄운다.
- **Enter** — 2초 녹화 시작 → 자동 전송.
- **Esc** — 취소.
- **Tab / 1~9** — 파트너 전환.
- **0 또는 A** — 전체 파트너에게 동시 발송.

## 시스템 요구사항

- macOS 26 Tahoe 이상
- Apple Silicon Mac (M1 이상)
```
