# 자동 얼굴 회신과 앱 자동 복구 변경 검토본

## 승인 요청 요약

이번 변경은 두 가지입니다.

1. macOS에서 핑을 받으면 자동 얼굴 회신을 항상 사용합니다.
2. Ping이 잠자기나 시스템 자원 부족으로 비정상 종료되면 자동으로 다시 실행합니다.

## 자동 얼굴 회신

- 모든 macOS 사용자는 새 핑을 실시간으로 받으면 얼굴 영상 3초를 자동 회신합니다.
- 설정 창의 `핑 받으면 자동으로 얼굴 회신` 항목과 토글을 완전히 삭제합니다.
- 기존에 이 설정을 꺼 둔 사용자도 업데이트 후에는 자동 회신이 적용됩니다.
- 다음 안전 조건은 유지합니다.
  - 자동 회신으로 온 영상에는 다시 회신하지 않습니다.
  - 이미 처리한 핑에는 중복 회신하지 않습니다.
  - 앱 실행 전 또는 60초가 지난 핑에는 회신하지 않습니다.
  - 카메라 권한이 없거나 카메라가 사용 중이면 회신하지 않습니다.
- 녹화 중 표시되는 인디케이터와 원래 보낸 사람 한 명에게만 회신하는 보호 장치는 유지합니다.

## 앱 자동 복구

현재 기능은 로그인 항목에 등록되어 있지만 실제 실행 중인 Ping을 감시하지 못하는 결함이 있습니다. 자동 업데이트 후에는 등록 정보가 이전 앱 빌드에 머무를 수도 있습니다.

수정 후 동작은 다음과 같습니다.

- launchd가 관리하는 Ping 프로세스를 실제 실행 프로세스로 사용합니다.
- 앱을 직접 열거나 Sparkle 업데이트가 끝난 뒤에는 KeepAlive 등록을 최신 앱으로 갱신합니다.
- 잠자기 중 디스크 부족, 메모리 압박, `cache_delete`, 크래시 등으로 비정상 종료되면 launchd가 Ping을 다시 실행합니다.
- 사용자가 메뉴에서 직접 `종료`하면 현재 로그인 세션에서는 다시 실행하지 않습니다.
- 로그인 시 자동 시작 설정과 시스템 설정에서 사용자가 내린 선택은 그대로 존중합니다.

macOS가 프로세스를 종료하는 것 자체를 막을 수는 없습니다. 이번 변경은 비정상 종료 후 자동 복구가 실제로 작동하도록 고칩니다.

## 변경하지 않는 범위

- 자동 얼굴 회신의 3초 길이, 회신 묶음 표시, 위치, 서버 계약
- Windows와 iOS의 자동 회신 및 앱 수명 주기
- macOS 13 최소 버전, Swift 6, 앱 샌드박스, Liquid Glass 호환 래퍼
- 사용자의 디스크 파일을 자동 삭제하거나 정리하는 기능

## 완료 기준

- 설정 창에서 자동 얼굴 회신 토글을 찾을 수 없습니다.
- 기존 OFF 저장값과 관계없이 안전 조건을 만족하는 새 핑에 자동 회신합니다.
- 설치된 앱의 단일 Ping 프로세스가 launchd의 KeepAlive 작업과 같은 PID로 실행됩니다.
- 비정상 종료 후 새 PID로 자동 복구됩니다.
- 메뉴에서 직접 종료한 경우에는 자동 복구되지 않습니다.
- 자동화 테스트 전체와 macOS Debug 빌드가 통과합니다.
