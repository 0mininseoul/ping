# Windows 실시간 수신·재생 검증 기록

작성일: 2026-09-30. 구현 커밋: `74962e1`, `60f7e21`, `775f625`. 전체 Windows 완성 목표 중 수신·재생 단계의 기록이다.

## 구현한 동작

- 인증된 Realtime 구독을 연결하고, 최신 토큰·heartbeat·join 응답·제한된 재연결을 처리한다. 변경 이벤트는 기존 RPC로 최신 데이터를 다시 읽는 신호로 사용한다. 구독 중에도 주기적인 재조회가 유지된다.
- 시작·재연결 중 가져온 영상과 새 live 영상을 구별한다. 계정별 중복 방지, 로컬 알림 실패 재시도, 알림 성공 이후 서버 확인을 적용한다. 느린 영상 다운로드가 다른 알림을 막지 않는다.
- 자동 재생 설정을 저장한다. 자동 수신·알림 클릭·히스토리 재생은 같은 준비 큐와 재생창 경로를 사용한다. 시작 중 알림 클릭은 계정 준비를 기다린다.
- 얼굴은 200 DIP 원형, 화면 영상 히스토리는 600 DIP 목표와 32 DIP 여백으로 표시한다. 발신 위치·작업 영역·화면 배율을 반영하고, 회신 영상 그룹이 겹치지 않게 배치한다. 종료 후 Enter 재생, Escape 닫기, 10초 자동 닫기를 지원한다.
- Mac의 아래쪽 기준 Y 좌표와 Windows의 위쪽 기준 Y 좌표를 송수신 경계에서 변환한다. 기존 Windows 로컬 위치 설정의 좌표계는 유지한다.
