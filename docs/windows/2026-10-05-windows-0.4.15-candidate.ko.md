# Ping Windows 0.4.15 설치 후보

현재 사용자 범위는 WNS 없는 트레이 수신과 재실행 동기화다. Azure 앱 등록, 종료 중 신규 원격 배너, 기존 Supabase·Vercel 운영 변경은 제외한다.

## 변경 내용

- startup/reconnect catch-up 영상과 채팅을 개별 배너 없이 기록과 읽지 않음으로 복원한다. 영상 notified acknowledgement는 갱신하되 seen은 변경하지 않는다. live 영상 자동 재생·fresh 자동 회신·사용자 재생은 기존 경로를 유지한다.
- Windows 자동 시작은 트레이에서 조용히 수신하며, 사용자가 대화창을 열 때 필요한 최초 설정을 안내한다. 일반 수동 실행과 트레이 열기는 대화창을 표시한다.
- 입력 컨트롤에 Pretendard 본문 폰트를 명시하고 읽지 않음 badge의 고대비 텍스트 색을 보완한다.
- 카메라·마이크·화면 캡처와 알림 영상 조회 실패를 한국어 복구 안내로 정리한다. 장치가 없어도 대화·사진·수신 경로는 유지한다.
- 설정에서 창 닫기·완전 종료·다음 실행 시 동기화의 차이를 설명한다. 기존 계정·저장 위치·3번 모니터 배치 계약을 유지한다.

## 설치물 생성

목표 파일은 `windows/dist/PingSetup-v0.4.15.exe`이며 x64/ARM64 MSIX와 오프라인 runtime dependencies를 포함한다. 기존 CI 인증서·package identity로 생성하며 공개 다운로드 채널과 운영 backend는 변경하지 않는다.

사용자 요청에 따라 workflow_dispatch의 `build_only=true`를 사용한다. 자동 테스트·smoke·실기·별도 리뷰는 실행하지 않는다. 서명과 installer payload 생성 시 기존 필수 무결성 방어는 유지한다. 패키징 성공은 앱 기능 검증 통과를 의미하지 않는다. 기존 0.4.14의 검증 기록을 이번 변경의 결과로 재사용하지 않는다.

## 나중에 사용자가 선택할 확인

실제 화면·한국어 IME·모니터 전환, 카메라/마이크 촬영, 실제 Mac 교차 사용, ARM64 기기 실행과 설치/업데이트 경험은 미검증이다. 장비 준비는 코드 작업의 완료를 막지 않는다. 공개 배포는 별도 결정이다. 기존 인증서로 MSIX를 서명하더라도 외부 EXE는 공개 코드서명이 없어 Windows 경고가 나타날 수 있다.
