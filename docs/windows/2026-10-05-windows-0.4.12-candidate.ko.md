소스는 `c2cd8ac669876ae05639a435e95257cd602e6930`이다. [CI37264332797](https://github.com/0mininseoul/ping/actions/runs/37264332797)는 Core285/App344와 x64·ARM64 패키지/EXE 생성을 완료했다. 공개 릴리즈와 웹 다운로드는 교체하지 않았다.

이번 후보에는 시작 중 알림 전달이 누락되는 경쟁 조건 수정과 메신저 모니터·위치·크기 복원이 함께 들어 있다. [시작 전달 검사](2026-10-05-windows-activation-handoff.ko.md)는 실제 Program queue의 결정적 재현,20,000회 시작 전달과1,000회 warm 전달을 검증했다. [창 배치 검사](2026-10-05-windows-messenger-placement.ko.md)는 DISPLAY3에서 정상 창 크기 복원과 최소화·최대화 시 보존을 검증했다. Pretendard Variable, 한글 본문14/21·보조12/18, Mac 참고 대화 화면·설정·첫 사용 안내를 유지한다.

실제 WinUI313개가 `windows/artifacts/ui-shell-3a18b08d48624df1835e7f86994d0721/result.json`에서 통과했다. 정상 Release는 경고0/오류0, 진단 타입0이다. 앞선 실제 서버 수신39개는 이전 후보의 변경 없는 수신 정책/재생 경로에 대한 증거이며 이번에 다시 실행한 수신 검사로 표시하지 않는다.

## 패키지와 설치

두 MSIX는 기존 인증서 `12D9D5539B1851EE1A0725CCFCB6A9CCD098DCDC`로 서명 Valid다. identity·버전·CPU·native DLL CPU, 새 창 배치·대화 기능 타입, Pretendard 원본 해시·OFL을 확인했다. 진단 타입0개, 개인 계정 파일 없음이다. 근거: `windows/artifacts/ci-37264332797/package-verification.json`.

설치 파일은 `windows/dist/PingSetup-v0.4.12.exe`,220,129,485 bytes다. 외부 EXE는 NotSigned이며 내부 MSIX 서명과 구분한다.

실제 EXE 업데이트0.4.11 → 0.4.12는 exit0, 설치 패키지0.4.12.0 / Status Ok다. 설치된 Core·App·native DLL·Pretendard·OFL은 검증 MSIX와 해시가 같다. 시작 메뉴·제거 프로그램·등록 버전도 확인했다. 자동 실행하지 않았다. `windows/artifacts/install-0412-23819caeacd34efcbb9920b5a6f0938f/upgrade-verification.json`이 근거다.

계정 세션·백업 두 파일은 설치 전 및 최초0.4.0 기준과 같다. 사용자의3번 모니터 요청에 맞춰 기존 배치 파일이 없음을 확인한 뒤 DISPLAY3 중앙640×620 DIP 배치 값을 추가했다. 이 파일도 업데이트 전후 바이트가 같다. 이는 설정한 배치 값 보존 증거이며 설치본이 실제 열린 화면을 확인한 것은 아니다. Native 배치 복원 검사는 위313개 결과를 따른다.

현재 installer script의 일반 설치 경로에 manifest 버전이 요청과 다른 패키지를 넣어 exit1로 배포 전에 거부되는 것을 확인했다. 기존0.4.11 설치와 계정·배치3개 파일은 그대로였다. `windows/artifacts/ci-37264332797/rejected-update-d80b0985abd340e99f78794967aa5aed/result.json`이 근거다. 이는 잘못된 입력 차단 검증이며 설치 중간 실패 rollback을 검증한 것은 아니다.

카메라·마이크 촬영, Mac 상대 송수신, 실제 ARM64, 혼합 DPI·고대비 화면, 설치본의 실제 OS 알림 클릭/cold activation 및 설치 중간 실패 복구는 남아 있다. 합성 영상·수학 검사·정상 업데이트와 이 항목들을 구분한다. 전체 제품 목표 완료를 뜻하지 않는다.

후속 정상 설치본 검사에서 일반 저장소 파일 보존만으로 런타임 계정 연속성을 입증할 수 없음을 확인했다. 패키지 저장소의 계정 경로를 초기화해야 하는 문제가 발견됐고0.4.13 소스에서 수정한다.0.4.12는 이 수정이 포함된 배포물이 아니다. [설치본 계정 경로와 실제 알림 검사](2026-10-05-windows-packaged-profile.ko.md)를 함께 따른다.
