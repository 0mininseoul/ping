# Ping Windows 0.4.3 설치 후보

설치 파일: `windows/dist/PingSetup-v0.4.3.exe`, 213927732 bytes (약204 MiB).

이 후보는 0.4.2의 대화/룸 UI 교정에 더해 Mac 소스 기반의 작은 설정 창과 첫 사용 안내를 포함한다. [화면 교정의 범위와 미완료 항목](2026-10-03-mac-design-correction.ko.md)을 참고한다. 현재 Mac 기준 커밋은 `5b21c1962de83d1e0d6c08ba8619802cbd53280b`이며 이번 확인에서도 변경이 없다.

Windows 11 24H2+(build26100+), x64 또는 ARM64에서 사용한다. 이전 Ping을 트레이에서 정상 종료한 뒤 EXE를 일반 실행한다. 전체 설치를 관리자 권한으로 실행하지 않는다. 최초 인증서 신뢰에만 UAC를 사용한다. 앱·.NET·Microsoft 런타임과 pinned 프로젝트의 공개 구성이 포함되므로 별도 런타임 설치나 Supabase 설정 입력이 필요 없다. 메시지 송수신에는 인터넷 연결이 필요하다.

정보 탭에서 `0.4.3.0`을 확인한다. 이 PC에서 이전 앱이 종료된 상태를 확인한 뒤 실제 EXE로 0.4.0 → 0.4.3 설치, 동봉 Inno 제거 프로그램으로 제거, 같은 EXE 재설치를 수행했다. 세 단계 모두 exit0이며 최종 설치 패키지는 0.4.3.0 / Status Ok다. 강제 종료하지 않았다.

실행 전에 기존 계정·설정 파일 두 개를 현재 사용자 프로필에 불투명 백업했다. 설치 후, 제거·복원 후, 재설치 후 세 번 모두 원래 파일의 SHA-256과 바이트 길이가 같았다. 시작 메뉴 바로가기와 제거 프로그램도 확인했다. 검사 중 앱 자동 실행을 제외했으므로 이는 파일 보존 검증이며 원격 계정 복구·메시지 송수신 성공을 뜻하지 않는다. 비공개 백업이나 토큰 내용을 공개 산출물에 넣지 않았다. 안전한 결과 기록은 `windows/artifacts/install-043-a36bccbe83f14b5ab02e3112ef9988f8/`에 있으며 사용자 프로필 백업을 커밋하지 않는다.

## 검증

- [CI 37039498491 성공](https://github.com/0mininseoul/ping/actions/runs/37039498491), 앱 소스 `5d4c37baef46bda554cdf333d0c6b35c67c90018`. Core271/App322 통과. x64·ARM64 Release와 Inno EXE compile 성공. 공개 릴리즈와 웹 다운로드는 교체하지 않았다.
- 정상 로컬 x64 Release 경고/오류0. DISPLAY3에서 실제 WinUI205 검사 통과. 렌더: `windows/artifacts/ui-shell-a5978e3aaf1f40109dc53e52c5b5402e/`.
- 두 실제 배포 MSIX의 identity/Publisher/버전/CPU, 원래 인증서 서명 `Valid` 확인. 배포 DLL에 MessageBubble와 GuidedSetupWindow/ViewModel이 있고 진단 타입은0개. 사용자 세션/설정/개인키가 포함되지 않았다.
- 오프라인 fallback bundle 생성 및 두 아키텍처의 OS PowerShell5.1 `-ValidateOnly` 통과. 이것은 읽기 전용 검사이며 설치 성공 검사가 아니다.
- 이번 재확인에서도 DISPLAY3 실제 WinUI205 검사 통과. 새 렌더는 `windows/artifacts/ui-shell-4ee13df66c3445d89362204a17b30b69/`다. 합성 테스트 데이터로 렌더링한 실제 WinUI 화면이며 현재 Mac 실기 화면과의 비교 결과가 아니다.

외부 EXE 자체는 `NotSigned`이며 내부 앱 MSIX는 원래 인증서 `12D9D5539B1851EE1A0725CCFCB6A9CCD098DCDC`로 서명됐다. 외부 EXE의 공인 서명이나 SmartScreen 평판을 확인했다고 주장하지 않는다.

## 남은 실제 사용 확인

현재 카메라가 없으며 사용자가 이를 확인했다. 카메라·마이크 실기 녹화와 Mac↔Windows 실제 메시지/영상/알림/자동 회신, ARM64 PC, iPhone/Watch 연결, 실행 후 원격 계정 사용 확인은 미완료다. 같은 상태의 Mac/Windows 실제 화면 비교도 남아 있다. 룸 관리의 폼 중심 구성은 전체 디자인 parity가 아니다. 이 후보를 전체 UI/UX·모든 기능의 완성으로 표시하지 않는다. 사용자 기존 룸이나 다른 사람에게 시험 메시지를 보내지 않았다.
