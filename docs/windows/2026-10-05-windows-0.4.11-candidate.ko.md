## 검증과 배포물

- [CI37260980070](https://github.com/0mininseoul/ping/actions/runs/37260980070)는 위 소스로 Core285/App339 검사와 x64·ARM64 MSIX/EXE 생성을 완료했다.

- 실제 서버와 기존 A/B 소유 QA 계정의 수신 검사39개가 통과했다. 실제 OS 알림 등록/큐, 얼굴·화면+얼굴 자동 재생, MP4 디코딩, seen, 다시 재생 시작 위치와 중복 방지를 확인했다. 합성 영상이며 실제 촬영은 아니다. QA 행·영상·룸을 정리하고 원래 사용자 파일을 보존했다. 결과는 `windows/artifacts/owned-native-8c92cbb6b78247d5a7a299eb4b538978/`에 있다.
- 두 MSIX는 원래 인증서 서명 `Valid`다. identity·버전·CPU·네이티브 DLL CPU, 메신저/사진/인라인 재생/안내 타입과 Pretendard 원본 해시·라이선스를 확인했다. 진단 타입0개, 개인 계정 파일이 없다. `windows/artifacts/ci-37260980070/package-verification.json`이 근거다.

## 이 PC에 적용

실제 EXE 업데이트0.4.10 → 0.4.11은 exit0, 패키지0.4.11.0 / Status Ok다. 설치된 Core·App·네이티브 DLL·Pretendard·OFL이 검증한 x64 MSIX와 해시가 같다. 시작 메뉴·제거 프로그램·제거 항목0.4.11을 확인했다.

원래 세션·백업 두 파일은 설치 전과 최초0.4.0 기준의 해시·길이가 같다. 별도 설정 파일이 없으므로 설정 값 보존 실기 검증을 뜻하지 않는다. 정상 설치본을 자동 실행하지 않았다. 결과는 `windows/artifacts/install-0411-3827445d6e3b4f0da0778d5b3bb048b5/upgrade-verification.json`이다.

공개 릴리즈·웹 다운로드는 교체하지 않았다. 카메라·마이크·Mac 상대 기기, 실제 ARM64, DPI·고대비와 Mac 실기 화면 대조, 설치본의 실제 알림 클릭/cold activation 및 업데이트 실패 복구는 남아 있다. framework-dependent 진단의 OS 알림 검증과 설치본 알림 클릭 검증을 구분한다. 전체 제품 목표 완료를 뜻하지 않는다.
