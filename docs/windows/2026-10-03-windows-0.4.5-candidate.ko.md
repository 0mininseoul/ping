# Ping Windows 0.4.5 설치 후보

Windows 소스는 `0ccaa6fe8f5214377c03f528a96e94eeb7e7bf6e`, Mac 기준은 `5b21c1962de83d1e0d6c08ba8619802cbd53280b`(0.3.80)이다. GitHub main이 이 Mac 기준과 같음을 다시 확인했다. Mac의 `RoomManagerWindow.swift`, `RoomDetailView.swift`, `RoomSearchView.swift`에 맞춰 메신저 안의 룸·연결 동선을 구현했다.

- 사이드바 +는 룸 생성, 검색 아이콘은 룸·사람 검색을 연다. 300ms 자동 검색과 Enter 즉시 검색, 같은 이름 룸의 방장 닉네임, 이미 연결한 대상 표시, 초대 코드·링크 참여를 제공한다.
- 헤더에서 멤버·초대 링크·이름 변경·나가기를 처리한다. 전체 사람 검색은 개인 대화를 연결하고, 멤버 목록의 사람 초대는 해당 룸에 초대한다. 받은 초대는 사이드바에서 수락·거절하며 만료되거나 다른 계정에 온 초대는 제외한다.
- 사진과 얼굴/화면 촬영은 작은 입력창 메뉴에 유지한다. 첫 사용 안내에서 만든 룸의 초대 화면도 메신저에서 연다. 기존 별도 관리 창은 설정의 관리 진입점에 남아 있으므로 모든 관리 화면을 완전히 통합했다는 뜻은 아니다.

서버에서 생성·참여·개인 연결·이름 변경·나가기가 성공한 뒤 목록 조회만 실패하면 확인된 상태를 보존한다. 사용자가 같은 작업을 다시 요청하게 하지 않는다. 이름 변경과 나가기는 확인 버튼을 눌렀을 때의 대상 룸을 검사한다. 닫힘 애니메이션 중 룸을 다시 선택해도 다른 룸에 작업하지 않는다. 계정 런타임을 분리하면 열려 있는 검색 화면과 요청을 취소한다. 서버 스키마·RLS·익명 인증·비공개 저장소는 변경하지 않았다.
