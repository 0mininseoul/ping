# Ping Windows 0.4.7 설치 후보

Windows 소스는 `60651643441f1cd02e3dd36de4cefab3cec21e2d`다. Mac 기준 `5b21c1962de83d1e0d6c08ba8619802cbd53280b`(0.3.80)의 사진 첨부 UI를 대조해 Windows에 빠진 사진 확대 보기를 추가했다.

대화 사진은 원본 비율과14 라운드로 표시한다. 클릭하면 파일명과 큰 미리보기를 네이티브 flyout에서 보여준다. 이미 읽은 사진을 재사용하며 창 크기·현재 테마·Pretendard를 따른다. 닫기·룸 변경·계정 전환 때 미리보기를 닫고 사진 참조를 비운다. 로딩 중이거나 디코더에서 읽을 수 없는 사진은 확대하지 않고 한국어 오류 상태를 표시한다. 상세 기준은 [사진 미리보기 문서](2026-10-03-windows-photo-preview.ko.md)를 따른다.

사진 진입점이 없다는 실제 WinUI 실패를 먼저 확인했다. 구현 후 DISPLAY3 실제 WinUI256개, App333개, 정상 x64 Release 빌드 경고/오류0을 확인했다. 최종 렌더는 `windows/artifacts/ui-shell-2e255482ee484622974008eed1349719/`다. 검증용 PNG는 로컬에서 생성했으며 실제 사용자 사진이나 Mac 실기 화면이 아니다.

인라인 영상 재생 등 확인된 Mac 사용 흐름 차이와 기기 QA는 남아 있다. 현재 PC에 카메라와 마이크가 없으므로 얼굴 녹화·Mac↔Windows 송수신 완료를 주장하지 않는다. 전체 제품 완료로 표시하지 않는다.


[CI37104561921](https://github.com/0mininseoul/ping/actions/runs/37104561921)가 동일 소스로 Core272/App333과 x64·ARM64 패키지/EXE를 생성했다. 두 MSIX의 기존 인증서 서명은 `Valid`다. manifest identity/버전/CPU, 네이티브 DLL CPU, 새 PhotoPreviewView/ShowPhotoPreview_Click, 기존 메신저, Pretendard 원본과 라이선스, 진단 타입0개와 개인 데이터 미포함을 확인했다. 공개 릴리즈와 웹 다운로드는 교체하지 않았다.

설치 파일은 `windows/dist/PingSetup-v0.4.7.exe`, 220094246 bytes(약210 MiB)다. 외부 EXE는 `NotSigned`, 내부 MSIX는 기존 인증서 서명 `Valid`다.
