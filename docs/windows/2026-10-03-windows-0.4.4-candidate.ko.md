# Ping Windows 0.4.4 설치 후보

Mac 기준 커밋은 `5b21c1962de83d1e0d6c08ba8619802cbd53280b`(0.3.80)이다. Windows 앱 소스는 `30e57763052d98aafbd7a344b796d471b7d9afaf`다. 이번 작업은 0.4.3의 메신저·설정·첫 사용 안내 교정에 더해 룸 관리의 남은 데모 폼을 제거한다.

룸 제목·인원과 작은 초대 링크/이름 변경/나가기 조작, 닉네임 멤버 목록을 표시한다. 생성과 이름 변경은 눌렀을 때만 네이티브 입력창으로 열린다. 나가기는 확인창을 거친다. 입력창이 열린 동안 선택 룸이 바뀌면 다른 룸을 변경하거나 나가지 않는다. 룸 정렬은 해당 행의 컨텍스트 메뉴에 있고, 검색 결과는 방장 닉네임으로 구분한다.

룸 생성이 실제로 성공한 뒤 목록 갱신만 실패하면 생성한 룸을 보존한다. 실패로 취급해 같은 룸을 다시 생성하지 않는다. 입력창은 1~16 grapheme을 검증하며 서비스는 UTF-16 길이로 유효한 이모지를 거부하지 않는다. 서비스의 기존 48자 경계는 grapheme 기준으로 유지한다. 서버 스키마·RLS·익명 인증은 변경하지 않았다.

로컬 Core272/App323, DISPLAY3 실제 WinUI216개 통과. 배포용 x64 Release 경고/오류0. 최종 렌더는 `windows/artifacts/ui-shell-c85e8bffab1b4da2b13863dffe50a16e/`다. 테스트 데이터로 렌더링한 실제 WinUI 화면이며 Mac 실행 화면과의 비교는 아니다. 실패를 먼저 확인한 정적 폼·이모지 길이·생성 후 갱신 실패 회귀 검사를 포함한다. 네이티브 입력창의 실패 입력 보존, 선택 변경 중 잘못된 룸 조작 방지, 다른 행의 컨텍스트 정렬까지 확인했다.

[CI 37098269756](https://github.com/0mininseoul/ping/actions/runs/37098269756)가 성공했다. 기존 인증서 `12D9D5539B1851EE1A0725CCFCB6A9CCD098DCDC`로 서명한 x64·ARM64 MSIX는 모두 `Valid`이며, manifest identity/버전/CPU와 네이티브 DLL CPU를 확인했다. 실제 배포 DLL에 새 메시지 UI·첫 사용 안내·룸 입력창이 있고 진단 타입은0개다. 사용자 세션·설정·개인키가 포함되지 않았다. 공개 릴리즈·웹 다운로드는 교체하지 않았다.

설치 파일은 `windows/dist/PingSetup-v0.4.4.exe`, 213913888 bytes(약204 MiB)다. 외부 EXE는 `NotSigned`, 내부 MSIX는 원래 인증서 서명 `Valid`다. Windows 11 24H2+(build26100+), x64/ARM64에 앱·런타임·공개 서버 구성이 포함된 EXE로 설치한다. 전체 설치는 현재 사용자 권한이며 최초 인증서 신뢰에만 UAC를 사용한다.

Inno 제거 항목 버전0.4.4, 제거 프로그램, 시작 메뉴 바로가기도 확인했다. 기존 계정·설정 파일 두 개는 새 백업뿐 아니라 최초 0.4.0의 해시·바이트 길이와도 같다. 실제 결과는 `windows/artifacts/install-044-a2105a7dfc53464593cbef5083b5ee8d/upgrade-verification.json`이다. 비공개 사용자 백업은 커밋하지 않았다.

검사 중 앱 자동 실행을 제외했다. 따라서 원격 계정 사용과 송수신이 성공했다는 뜻은 아니다. DISPLAY3의 진단 화면 배치와 정상 설치 앱의 기본 창 배치도 구분한다. 사용자 기존 앱을 강제 종료하거나 메인 모니터에 시험 창을 띄우지 않았다.

0.4.3 EXE의 실제 0.4.0 → 0.4.3 설치, 제거, 재설치는 모두 exit0으로 성공했고 계정·설정 파일 두 개의 해시와 길이를 보존했다. 앱 실행 후 원격 계정 사용, 카메라·마이크 실기 녹화, Mac↔Windows 실기 송수신, ARM64 PC, iPhone/Watch 연결 및 실제 Mac 같은 상태 화면 비교는 미완료다. 메신저/관리 창 통합과 Mac 검색 sheet·멤버 popover까지 완전히 같아졌다는 주장도 하지 않는다. 카메라가 없다는 사용자 답변을 유지하며 기존 사람이나 룸에 시험 메시지를 보내지 않았다.
