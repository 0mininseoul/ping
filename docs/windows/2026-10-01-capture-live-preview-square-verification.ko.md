# Windows 녹화 미리보기와 얼굴 정사각형 저장

화면+얼굴 거울은 녹화하는 동안 저장할 합성 프레임을 계속 보여준다. 네이티브 V5가 기존 카메라·마이크 선택과 캡처 파이프라인을 사용하며, MP4에 기록한 BGRA 프레임을 동기 콜백으로 전달한다. 별도 카메라를 열지 않는다. 콜백 포인터는 호출 중에만 유효하므로 관리 코드가 즉시 복사하며, 델리게이트와 취소 핸들은 실제 네이티브 반환까지 유지한다.

WinUI는 최신 프레임 하나와 진행 중인 비트맵 변환 하나만 유지한다. 33ms 타이머로 표시하며, 느린 UI에서 프레임마다 작업을 누적하지 않는다. 합성 프레임이 보이면 별도 얼굴 버블을 숨긴다. 리뷰·종료 시 타이머를 멈추고 비트맵 작업을 기다린 뒤 소스를 해제한다. 이전 녹화의 콜백은 세대 값으로 무효화한다.

얼굴 전용 녹화는 기존 단일 MediaCapture 세션에서 3초를 녹화하고, 중앙 정사각형 H264/AAC 파일로 내보낸 뒤 원본 임시 파일을 삭제한다. Windows MediaComposition의 정사각형 출력에 원본 영상을 같은 비율로 중앙 배치하고 밖의 영역을 잘라낸다. 오버레이 오디오를 명시적으로 켜며, 실패·취소 시 부분 출력 파일을 제거한다. 완료 대기 동안 카메라 소유권을 유지한다. API 근거: [Microsoft 영상 합성 및 오버레이 문서](https://learn.microsoft.com/en-us/windows/apps/develop/media-authoring-processing/media-compositions-and-editing).

## 검증

- Core Release 254개, App Release 297개 통과. 선택한 카메라·마이크·viewport가 미리보기 녹화 경로까지 전달되고 취소 중 핸들·소유권이 실제 반환까지 유지되는 사례 포함.
- 네이티브 Release 180개 통과. 합성 소스에서 실제 V5/MP4 writer가 1초 동안 30개의 540×304 BGRA 프레임을 전달하고 반환 뒤 콜백이 끝남을 확인. 아티팩트: `windows/artifacts/native-tests-2123f5dc16c140348ec0e25c6bfef92a`.
- 실제 WinUI 129개 통과. 작업 스레드에서 연속 전달한 프레임의 녹색 픽셀이 실제 거울에 렌더링되고, 별도 얼굴 버블 숨김·리뷰 전환·늦은 프레임 무시를 확인. 아티팩트: `windows/artifacts/ui-shell-e9c674bdad954acabac51d364acf35fa`.
- 정상 x64 Release와 서명하지 않은 검증용 MSIX 빌드 성공(경고·오류 0). MSIX: `windows/artifacts/local-x64-1708ac68853b4b89a2c431b2039babf4`. 공개 설치 배포물 검증은 아니다.
- 같은 WinUI 검사에서 합성 영상 320×192와 440Hz 오디오를 실제 Windows API로 인코딩한 뒤 실제 얼굴 exporter를 실행. 192×192 H264, 48kHz mono AAC, 3초 길이와 디코딩한 중앙 녹색 밴드를 확인했다. 원본의 바깥 빨강·파랑 영역을 정사각형에 눌러 넣지 않는다. AAC 이름은 메타데이터 `AAC`와 상수 `Aac`의 대소문자를 구분하지 않고 비교한다.

실제 데스크톱·카메라·마이크·운영 계정·Supabase는 사용하지 않았다. 소리의 실제 청취, 장치 드라이버의 회전·권한·A/V 동기화, 다중 모니터 DPI 전환, 물리 입력과 Mac 상호 송수신은 별도 기기 QA가 남아 있다. 설치 EXE·서명·업데이트 검증은 이후 배포 단계다.
