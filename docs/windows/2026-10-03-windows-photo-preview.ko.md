# 대화 사진 확대 보기

현재 Mac 기준 `5b21c1962de83d1e0d6c08ba8619802cbd53280b`의 `Ping/UI/History/ChatImageAttachmentView.swift`는 사진을 클릭하면 파일명과 큰 이미지 미리보기를 제공한다. Windows 0.4.6에는 그 진입점이 없어 이 빠진 사용 흐름을 구현한다.

- 대화 사진은 Mac처럼 최대240×260, 최소80의 영역과 14 라운드를 사용하며 원본 비율을 유지한다. 메타데이터가 없으면200×160 영역을 쓴다.
- 로딩된 사진 버튼을 클릭하거나 키보드로 활성화하면 네이티브 flyout에서 파일명과 큰 사진을 표시한다. 이미 내려받은 BitmapImage를 재사용하고 추가 다운로드를 시작하지 않는다. 창 안에 맞춰 크기를 제한하고 현재 라이트/다크 테마와 Pretendard를 유지한다.
- 닫기, 룸 변경, 계정 런타임 분리 시 미리보기를 닫고 사진 참조를 비운다. 로딩 중 사진과 읽을 수 없는 사진은 확대하지 않는다. 디코더 실패도 한국어 상태로 표시한다.

실제 WinUI 검사에서 사진 버튼이 없다는 실패를 먼저 확인했다(`ui-shell-4f9b3a9b1dbb4feeb7ea86f997c7466c`). 구현 후 DISPLAY3의 전체 UI 검사256개와 기존 App333개를 통과했다. 큰 이미지와 파일명, 닫기 후 참조 해제, 룸 이동, 계정 전환, 잘못된 이미지 파일의 디코더 실패를 확인했다. 최종 렌더는 `windows/artifacts/ui-shell-2e255482ee484622974008eed1349719/`다.

사진은 로컬에서 생성한 소유한 검증용 PNG이고 네트워크 서비스는 fixture다. 실제 사용자 사진이나 Mac 실기 화면이 아니다. 실제 기기 간 송수신과 Mac 전체 화면 대조 완료를 뜻하지 않는다. 인라인 영상 등 남은 Mac 사용 흐름은 다음 구현 대상으로 유지한다.
