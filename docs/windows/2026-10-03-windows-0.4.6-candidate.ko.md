# Ping Windows 0.4.6 설치 후보

Windows 소스는 `3f716ef2a476ac6e53ff12f358930eee0491f3bf`다. 0.4.5의 메신저·검색·룸·초대 기능 위에 사용자가 요청한 글꼴과 UI 세부 요소 개선을 적용했다.

공식 Pretendard Variable 1.3.9 원본과 SIL OFL 1.1 전문을 앱에 포함한다. 실행 중 다운로드나 시스템 글꼴 설치가 필요 없다. 대화 본문·룸·검색·멤버·설정·첫 실행에 공통 글꼴을 적용하고, 본문 14 DIP / 줄 높이21, 보조 정보12 DIP / 줄 높이18을 기준으로 조정했다. 메시지 입력창의 안쪽 여백과 작은 초대 버튼도 개선했다. 아이콘은 Windows 아이콘 글꼴을 유지한다. 상세 기준은 [글꼴 개선 문서](2026-10-03-windows-typography.ko.md)를 따른다.

DISPLAY3에서 실제 WinUI 검사247개를 통과했다. 네이티브 입력창의 글꼴과 크기, 사이드바의 글꼴, 아이콘 폰트 보존, 시스템 fallback과 다른 실제 글리프 폭을 확인했다. 라이트·다크·최소 창 크기·검색·설정·첫 실행 등 실제 UI 렌더는 `windows/artifacts/ui-shell-ac2d3484e0b9466f8711e63cb703ade8/`다. 정상 x64 Release 빌드도 경고/오류0으로 통과했다. 이 화면들은 소유한 테스트 데이터이며 실제 Mac 화면과의 시각적 대조를 뜻하지 않는다.

0.4.5의 기기 QA 한계는 유지한다. 현재 PC에 카메라와 마이크가 없으므로 실기 얼굴 녹화와 Mac↔Windows 송수신을 완료했다고 표시하지 않는다. 정상 설치본과 DISPLAY3 진단 창의 배치도 구분한다. 전체 제품 완료로 표시하지 않는다.


[CI 37102931643](https://github.com/0mininseoul/ping/actions/runs/37102931643)가 동일 소스로 Core272/App333 및 x64·ARM64 패키지/EXE를 생성했다. 두 MSIX는 기존 인증서 `12D9D5539B1851EE1A0725CCFCB6A9CCD098DCDC`의 서명 `Valid`이며, 버전·identity·CPU·네이티브 DLL·메신저 타입·진단 타입0개·개인 데이터 미포함을 확인했다. Pretendard 파일은 공식 원본 SHA-256과 같고 OFL.txt도 포함한다. 공개 릴리즈와 웹 다운로드는 교체하지 않았다.

설치 파일은 `windows/dist/PingSetup-v0.4.6.exe`, 220083868 bytes(약210 MiB)다. 외부 EXE는 `NotSigned`, 내부 MSIX는 원래 인증서 서명 `Valid`다.
