# Ping Windows 0.4.10 설치 후보

Windows 빌드 소스는 `82b89d706c95d8bcac1a7e507ff818188968970b`다. Mac 기준 `5b21c1962de83d1e0d6c08ba8619802cbd53280b`(0.3.80)과 대조한 대화 표시·본문 링크를 포함한다. 1:1은 이름을 숨기고 그룹은 받은 행에 표시한다. 본문 웹·메일 링크가 각각 열리는 네이티브 텍스트이며 한글·이모지·줄바꿈의 선택·복사를 유지한다. 잘못된 이메일은 대화 로딩을 막지 않는다. [대화 표시 기록](2026-10-05-windows-conversation-text.ko.md)을 따른다.

Pretendard Variable을 앱에 포함해 본문 14 DIP/줄 높이 21 DIP, 보조 글자 12 DIP/18 DIP와 입력창 여백을 일관되게 적용한다. 기존 메신저·설정·첫 사용 안내, 사진 입력·확대와 원형 얼굴 재생을 유지한다. 실제 서버 검증에서 발견한 사진 크기 누락을 수정해 방향을 반영한 너비·높이를 전송한다.

## 검증과 배포물

- [CI 37257016117](https://github.com/0mininseoul/ping/actions/runs/37257016117)가 위 소스로 성공했다. Core 283/App 339개 통과, x64·ARM64 MSIX와 EXE를 생성했다.
- DISPLAY3 대화 전용 실제 WinUI 7개 통과. 두 소유 테스트 계정과 실제 서버를 사용한 네이티브 UI 25개도 통과했다. 텍스트·답장·리액션·사진 업로드/수신 디코딩과 합성 3초 MP4의 인라인 재생/seen 반영을 확인했다. 자세한 결과와 실패·복구 기록은 [실제 서버 QA](2026-10-05-windows-native-live-qa.ko.md)에 있다.
- 두 패키지 서명은 원래 인증서의 `Valid`다. identity·버전·CPU·네이티브 DLL CPU, 새 LinkedMessageText와 ChatMediaStorageService, 기존 사진 입력·미리보기·인라인 재생·룸 관리·안내, Pretendard 원본 해시와 라이선스를 확인했다. 진단 타입 0개, 개인 계정 파일이 없다. `windows/artifacts/ci-37257016117/package-verification.json`과 verifier가 근거다.
- ARM64는 패키지 검사만 했으며 실제 ARM64 기기 실행은 확인하지 않았다. 외부 EXE 서명은 `NotSigned`이며 내부 MSIX 서명과 구별한다.

## 이 PC에 적용

실제 EXE 업데이트 0.4.9 → 0.4.10은 exit 0이다. 설치된 패키지는 0.4.10.0 / Status Ok다. 설치된 앱·네이티브 DLL·Pretendard·OFL은 검증한 x64 MSIX와 해시가 같다. 시작 메뉴·제거 프로그램·제거 항목 0.4.10을 확인했다.

기존 세션·백업 두 파일은 설치 전과 최초 0.4.0 기준의 해시·길이가 같다. 별도 설정 파일이 없으므로 설정 값 보존 실기 검증을 뜻하지 않는다. 정상 설치본을 자동 실행하지 않았다. 결과는 `windows/artifacts/install-0410-ae168ba3e7df43a8aca00b572cf95146/upgrade-verification.json`이다.

공개 릴리즈·웹 다운로드는 교체하지 않았으며 공개 채널은 0.3.46이다. 전체 UI suite의 사진 입력 키보드 foreground guard 실패는 미해결 진단 항목으로 남아 있다. 이전 0.4.9 전체 297개 통과와 이번 집중 7개/실제 서버 25개를 같은 결과로 합산하지 않는다. 카메라·마이크·Mac 상대 기기가 없어 실제 촬영과 Mac↔Windows 송수신은 검증하지 못했다. DPI별·Mac 실기 전체 시각적 대조도 남아 있다. 전체 제품 목표는 계속 진행한다.
