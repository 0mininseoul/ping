## 실제 Windows 검증

실제 EXE로0.4.12→0.4.13 업데이트, 제거,0.4.13 재설치가 각각 exit0으로 완료됐다. 현재 설치는0.4.13.0 / Status Ok다. 일반 저장소 네 파일과 패키지 런타임 저장소의 세 파일을 비교했다. 세션/백업은 최초 계정 보존 기준과 같으며 DISPLAY3 배치 값도 보존됐다. 설치된 Core·App·native DLL·Pretendard·OFL 해시는 검증 MSIX와 같다. 설치된 보존/제거 스크립트는 줄바꿈 정규화 후 소스와 일치한다. 시작 메뉴·제거 프로그램·등록 버전도 확인했다. 근거: `windows/artifacts/install-0413-f2697ae6d9a741a7a358ffd9a783ba9f`의 `upgrade-verification.json`, `removed-verification.json`, `reinstall-verification.json`.

원래 계정과 다른 기존 QA 계정 두 개로 정상 재설치본을 실행했다. 실제 런타임 세션이 QA 수신 계정과 일치했고, 상대가 보낸 다른 룸의 텍스트가 읽지 않음1로 조회됐다. Windows 알림 기록에는 해당 메시지 ID의 실제 Ping 알림1개가 생성됐다. 검사 종료 후 QA 메시지와 두 룸 멤버십을 정리했으며 원래 일반/패키지 저장소 일곱 파일을 바이트 그대로 복원했다. 원래 사용자 세션은 네트워크 인증에 사용하지 않았다. 근거: `windows/artifacts/packaged-toast-0413-6876ac33871342f4b695081676942eca`의 `effective-identity-diagnostic.json`, `before-warm.json`, `toast-history.json`, `profile-restoration.json`, `server-cleanup.json`. 현재 앱은 종료 상태다.
