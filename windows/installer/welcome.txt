[Ping for Windows 설치 안내]

이 프로그램은 안전하고 격리된 Windows MSIX 패키지 배포 방식을 활용하여 시스템을 무단으로 변경하지 않고 안전하게 설치를 완료합니다.

[개인정보 처리 및 동의 안내]
Ping은 이메일이나 소셜 로그인 정보 등 어떠한 민감한 개인 식별 정보도 수집하지 않습니다. Anonymous Auth(익명 인증) 방식의 계정 세션으로만 동작하며, 기기 고유의 비식별 코드만을 활용하여 파트너 간의 3초 비디오 송수신을 수행합니다.

설치 진행 시 다음 작업이 수행됩니다:
- Ping 개발자 서명 보안 인증서 등록 (Sideload 신뢰용)
- 최신 버전의 Windows MSIX 패키지 다운로드 및 등록
- 바탕화면 바로가기 생성 및 Windows 시작 시 자동 실행 설정 (선택 가능)

설치 중 경로 선택 화면이 나타나지 않는 것은 Windows가 앱 설치 경로를 안전하게 자동 관리하기 때문입니다. 설치 완료 후 시작 메뉴 및 바탕화면을 통해 앱을 즉시 실행하실 수 있습니다.
