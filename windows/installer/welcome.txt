[Ping for Windows 설치]

Ping은 익명 인증 기반의 3초 영상 메시지 데스크톱 앱입니다. 이메일·소셜 로그인 등 민감한 개인정보를 수집하지 않으며, 기기 고유의 비식별 코드로만 파트너 간 영상을 주고받습니다.

설치 시 다음이 진행됩니다.
- Ping 개발자 서명 인증서 등록 (Sideload 신뢰용)
- EXE에 포함된 현재 PC용 Ping 앱과 Windows App Runtime 설치
- 로그인한 Windows 사용자 계정에 앱 등록 및 일반 권한으로 실행
- 바탕화면 바로가기 만들기 (선택 가능)

설치 파일에는 앱과 런타임이 함께 들어 있습니다. 메시지를 보내고 받으려면 인터넷 연결이 필요합니다. Windows 로그인 시 자동 시작은 설치 후 Ping 설정에서 선택할 수 있습니다.

설치 경로는 Windows가 안전하게 자동 관리합니다. 계속하려면 '다음'을 눌러주세요.
